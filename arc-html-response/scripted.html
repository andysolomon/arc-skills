stepper: one step at a time

For a walkthrough the reader should take in order. Without the script it is a numbered list. With it, the reader moves with Back and Next, and the count says where they are.

  1. The browser asks for the page

    One request to the edge, with the session cookie.

  2. The edge checks the session

    A valid session goes on; an expired one is sent to sign-in.

  3. The worker renders the view

    It reads the user's data and returns finished HTML.

  4. The browser shows it

    No second round trip: the first paint has the data.
