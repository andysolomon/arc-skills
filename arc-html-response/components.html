flow: a straight line of steps

For a straight line of five steps or fewer. Two SVGs: a row for wide screens, a column for phones. Flowing dashes show direction and stop under reduced motion. Mark the step that matters with .key. Anything with a fork uses diagram below.

diagram: forks, branches, anything past a straight line

Drawn to diagram-design's rules: right-angle elbows, a masked label on every branch, names in sans with mono sublabels, one accent path. It keeps its width and scrolls inside its own box on phones. With the diagram-design skill installed, pick the type and layout there and write the result into this shell.

Motion rules

Every animation on this page sits inside @media (prefers-reduced-motion: no-preference) and animates from a start state with backwards fill, so a still frame shows the finished chart. No scroll-driven animation: T3's frame never scrolls, so the content would stay hidden.

Timings come from four tokens on :root: --t-micro (160ms, hover), --t-state (220ms, a tab or <details> opening), --t-enter (500ms, entrances) and --stagger (60ms between items). The headline and lede never move; the page's main chart or diagram moves first, and supporting rows follow.
